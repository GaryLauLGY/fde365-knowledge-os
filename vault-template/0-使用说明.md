# 六类资产库使用说明

这套目录保存一家业务可以反复使用的资料。`.kb/config.yaml` 记录真实路径，`kb-*` 根据它读写当前知识库。

## 6 个库

| 目录 | 保存内容 |
| --- | --- |
| `1-老板说明书` | 身份、判断、表达习惯和不能说的内容 |
| `2-产品库` | 产品、价格、承诺、交付和异议 |
| `3-客户需求库` | 客户原话、问题、成交和未成交记录 |
| `4-素材案例库` | 事件、案例、数据、对话和结果 |
| `5-方法论库` | 已经实际使用的方法、步骤和判断条件 |
| `6-内容生产` | 选题、草稿、审核、发布和数据复盘 |

## 开始

1. 复制这整个目录并改成项目名称。
2. 在目录中调用 `/kb-start`。
3. 空库使用 `/kb-interview`。
4. 已有录音、聊天或旧文档时，把文件放进 `0-录音处理/待处理录音`，再使用 `/kb-ingest`。

## 规则

- 原始文件保留。
- 业务事实、用户原话、AI 推断和未知项分开。
- 新条目写明来源和日期。
- 分类不确定时先放待确认区。
- 移动、覆盖和删除前先确认。
- 状态、索引和日志只写入当前目录的 `.kb`。
