# 六类资产库使用说明

这套目录保存一家业务可以反复使用的资料。`.fde/config.yaml` 记录真实路径，中文技能根据它读写当前知识库。

## 6 个库

| 目录 | 保存内容 |
| --- | --- |
| `1-个人说明书` | 身份、判断、表达习惯和不能说的内容 |
| `2-产品库` | 产品、价格、承诺、交付和异议 |
| `3-客户需求库` | 客户原话、问题、成交和未成交记录 |
| `4-素材案例库` | 事件、案例、数据、对话和结果 |
| `5-方法论库` | 已经实际使用的方法、步骤和判断条件 |
| `6-内容生产` | 选题、草稿、审核和发布；发布数据可选分析 |

## 开始

1. 复制这整个目录并改成项目名称。
2. 在目录中调用 `/开始使用`。
3. 空库使用 `/建库采访`。
4. 已有录音、聊天、文档、图片或其他原始材料时，把文件放进 `0-待处理材料/待处理`，再使用 `/材料入库`。分流预览只显示在右侧对话；处理成功后原记录自动标记为已处理并排到列表底部，不能批量选择，原始材料保持原路径且不会删除。

## 规则

- 原始文件保留。
- 业务事实、用户原话、AI 推断和未知项分开。
- 新条目写明来源和日期。
- 分类不确定时先放待确认区。
- 移动、覆盖和删除前先确认。
- 状态、索引和日志只写入当前目录的 `.fde`。
- 点击资产网络的“整理关联”时，先核对关系依据；确认后把关系写入两端资产的 `## 关联资产` 和真实 Obsidian Wikilink。Canvas 不能代替双链。
