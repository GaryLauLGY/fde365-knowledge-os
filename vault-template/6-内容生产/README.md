# 内容生产

这里保存内容从选题到发布的状态。一个文件同时只处在一个阶段；每次推进前先确认当前环节已经完成。

## 阶段

- `选题`：已经有来源、读者和核心问题。
- `草稿`：正在写，尚未审核。
- `待审核`：等待事实、表达和平台检查。
- `待发布`：审核通过，等待发布。
- `已发布`：流程终点，记录平台、链接和日期。

## 发布数据分析（可选）

发布后的 CSV、Excel、TSV 或 JSON 数据放进 `发布数据`。这些文件只作为 `/传播复盘` 的分析输入，不是新的内容阶段，也不会把“已发布”稿件继续推进。

## 内容文件最少包含

```markdown
# 标题

- 目标读者：
- 目标平台：
- 当前阶段：
- 来源文件：
- 创建日期：
- 最后修改：

## 正文或提纲

## 未核实项

## 发布记录
```

移动阶段时更新文件中的当前阶段，不重复复制同一稿件。选题未补全时用 `/内容写作`，草稿未完成时继续用 `/内容写作`，审核未完成时用 `/内容审核`；由用户确认完成后再推进。
