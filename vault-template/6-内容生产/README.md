# 内容生产

这里保存内容从选题到复盘的状态。一个文件同时只处在一个阶段。

## 阶段

- `选题`：已经有来源、读者和核心问题。
- `草稿`：正在写，尚未审核。
- `待审核`：等待事实、表达和平台检查。
- `待发布`：审核通过，等待发布。
- `已发布`：记录平台、链接和日期。
- `数据复盘`：记录数据、评论和下一次实验。

## 内容文件最少包含

```markdown
# 标题

- 目标读者：
- 目标平台：
- 当前阶段：
- 来源文件：
- 创建日期：
- 最后修改：

## 正文或提纲

## 未核实项

## 发布记录
```

移动阶段时更新文件中的当前阶段，不重复复制同一稿件。
