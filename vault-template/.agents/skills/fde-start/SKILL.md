# 知识库入口

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- `.fde/config.yaml`
- 六类资产库的文件数量和最近更新时间
- 当前对话中的目标、材料和限制

## 必须保留的能力

- 完整讲解第一次使用方法
- 任务开始前选择一个入口
- 根据上一步结果继续导航
- 路由后直接执行，不让用户重复输入

## 执行

1. 用户要求新手说明时，先讲可以交什么、系统怎样处理、会得到什么，再进入真实任务。
2. 判断是空库、进料、查资料、做判断、做内容还是维护任务。
3. 信息足够时直接选一个 Skill；信息不足时只问一个会改变路由的问题。
4. 任务完成后读取实际结果，再选一个下一入口；说明依据并直接继续。

## 交付

- 当前任务类型
- 选择的一个 Skill
- 选择依据
- 执行所需的现有输入

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 本 Skill 不写业务资产，只读取状态

## 停止条件

- 找不到配置时停止路由并询问知识库位置
- 两个方向无法区分时只问一个问题

## 接续

- 空库用 fde-interview
- 有原始材料用 fde-ingest
- 已有明确任务时进入对应 Skill

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
