# 决策记录方法

## 输入

- 要做的决定
- 选项
- 证据
- 限制
- 已有类似记录

## 步骤

1. 建立领域、事件、快照、模式四层记录。
2. 确认决策人、截止时间和可逆性，为每个选项记录事实、假设、代价和失败信号。
3. 保存带来源且写后不改的决策快照，写下选择及未选原因。
4. 按日期回填结果和判断变化，不覆盖旧快照。
5. 多次记录后提炼重复模式，并生成当前状态画像。

## 交付

- 领域档案
- 决策事件
- 不可改快照
- 当前选择
- 关键假设
- 回填计划
- 模式和状态画像

## 停止

- 决策人不是用户时标明权限
- 证据不足时可记录暂定选择但不能写成确定结论
- 不可逆高风险决定先提示专业核验
