# 传播复盘方法

## 输入

- 原内容
- 平台数据
- 评论和转发语
- 发布时间和分发方式
- 同账号基线

## 步骤

1. 先确认用户上传或回填的发布数据对应哪一篇已发布内容，并确认指标口径。
2. 没有数据时只列出需要补充的指标和平台导出文件，不生成数据结论。
3. 有数据时确认口径和基线，拆分曝光、停留、互动、转发和转化信号。
4. 用评论原话验证受众情绪和有效立场，不替读者发明动机。
5. 输出可继续讨论的方向、反证和下一次实验。

## 交付

- 数据摘要
- 有效信号
- 可能机制
- 反证
- 下一次实验

## 停止

- 没有用户上传或回填的真实数据时不生成数据结论
- 平台口径不同不直接横比
- 相关性不写成因果
