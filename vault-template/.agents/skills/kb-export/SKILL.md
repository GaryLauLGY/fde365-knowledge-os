# 导出聊天

<!-- KB-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.kb/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 用户指定的 Agent 和项目
- 本地会话索引
- 用户选择的会话范围
- `scripts/export_chat.py`

## 必须保留的能力

- 列出本地项目和会话
- 支持单选、多选、最近记录和批量选择
- 导出用户与助手的可读 Markdown
- 过滤工具日志并保留时间和源文件

## 执行

1. 先识别宿主和本地会话位置，不扫描无关目录。
2. 使用 `scripts/export_chat.py list` 列出日期、项目和首条消息，让用户选择。
3. 支持单选、多选、最近记录和全部；导出前显示会话数、目标目录和隐私范围。
4. 使用脚本只提取用户与助手可读文本，生成 Markdown 和来源清单。

## 交付

- 导出文件列表
- 会话时间范围
- 消息数量
- 未能解析的记录

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 默认写入知识库收件箱的聊天导出目录
- 不改动本地会话源文件

## 停止条件

- 宿主格式未知时不猜解析规则
- 未获确认时不批量导出
- 含敏感信息时先提醒用户选择范围

## 接续

- 导出后用 kb-ingest 入库

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
