# 安全检查

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 默认 Agent 技能目录或用户指定目录
- SKILL.md
- scripts 和可执行文件
- 链接目标
- scripts/audit_skill.py

## 必须保留的能力

- 扫描默认 Agent 技能目录和指定目录
- 检查广告导流、隐蔽商业意图和任务劫持
- 检查外部调用和敏感数据读取
- 报告文件、行号和原文证据
- 确认后隔离并支持恢复

## 执行

1. 使用脚本枚举文件、链接和可执行入口。
2. 查找广告导流、隐蔽商业关系、任务劫持、网络发送、凭证读取、外部安装和删除移动。
3. 为每个命中给文件、行号、原文和可能影响。
4. 先报告；用户逐项确认后才移动到当前知识库隔离区，并保留恢复记录。

## 交付

- 扫描范围
- 风险项
- 证据位置
- 误报可能
- 建议动作

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 报告可写入 `.fde/logs`
- 隔离只进入 `.fde/quarantine`

## 停止条件

- 扫描结果不等于安全保证
- 不得自动删除
- 不得读取凭证内容来证明风险

## 接续

- 不提供连接本机 Claude Code 或 Codex 的功能；不要修改全局客户端配置
- 整体工作台用 项目设置

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
