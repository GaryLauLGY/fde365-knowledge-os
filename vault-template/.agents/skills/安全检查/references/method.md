# 技能风险检查方法

## 输入

- 默认 Agent 技能目录或用户指定目录
- SKILL.md
- scripts 和可执行文件
- 链接目标
- scripts/audit_skill.py

## 步骤

1. 使用脚本枚举文件、链接和可执行入口。
2. 查找广告导流、隐蔽商业关系、任务劫持、网络发送、凭证读取、外部安装和删除移动。
3. 为每个命中给文件、行号、原文和可能影响。
4. 先报告；用户逐项确认后才移动到当前知识库隔离区，并保留恢复记录。

## 交付

- 扫描范围
- 风险项
- 证据位置
- 误报可能
- 建议动作

## 停止

- 扫描结果不等于安全保证
- 不得自动删除
- 不得读取凭证内容来证明风险
