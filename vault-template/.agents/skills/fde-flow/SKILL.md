# 口播衔接

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 逐字稿
- 目标时长
- 核心观点
- 必须保留的原话

## 必须保留的能力

- 检查段落间承接
- 检查段落内信息密度
- 检查句子口播流畅度
- 标出可能划走的位置
- 诊断后可按确认生成标记式改稿

## 执行

1. 按听众能感知的意思分段。
2. 为每段标出作用：提出、解释、证明、转折或行动。
3. 找出无承接、重复证明、概念跳跃和单段过载。
4. 给出删、移、补一句的最小调整。

## 交付

- 段落功能表
- 断点
- 重复
- 最小调整
- 调整后顺序

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 默认只出标记稿；用户确认后另存修改版

## 停止条件

- 核心观点不清时先停止结构调整
- 不把口语全部改成书面语
- 不删除用户要求保留的原话

## 接续

- 开头用 fde-hook
- 整体审核用 fde-review

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
