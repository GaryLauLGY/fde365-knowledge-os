# 内容开头

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 现有开头
- 选题
- 客户原话
- 案例冲突
- 平台和时长

## 必须保留的能力

- 诊断现有开头问题
- 生成多个不同切入版本
- 说明适合的读者和承接方式
- 不制造正文没有的承诺

## 执行

1. 判断开头是否说明对象、问题和继续看的理由。
2. 找出最强的真实冲突、结果或原话。
3. 生成 3 个不同切入版本，不制造假数字和假危机。
4. 说明每版适合的读者和后文承接。

## 交付

- 问题诊断
- 3 个开头
- 选择建议
- 承接句
- 来源

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 用户选择后写入对应草稿的新版本

## 停止条件

- 选题本身不成立时停止改开头
- 没有证据时不用夸张结果
- 不生成与后文无关的钩子

## 接续

- 检查全文用 fde-review
- 检查衔接用 fde-flow

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
