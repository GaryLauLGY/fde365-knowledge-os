# 决策记录

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 要做的决定
- 选项
- 证据
- 限制
- 已有类似记录

## 必须保留的能力

- 为长期领域建立决策记录
- 保存带来源且写后不改的快照
- 支持结果回填和判断变化
- 从多次记录提炼重复模式
- 生成当前状态画像

## 执行

1. 建立领域、事件、快照、模式四层记录。
2. 确认决策人、截止时间和可逆性，为每个选项记录事实、假设、代价和失败信号。
3. 保存带来源且写后不改的决策快照，写下选择及未选原因。
4. 按日期回填结果和判断变化，不覆盖旧快照。
5. 多次记录后提炼重复模式，并生成当前状态画像。

## 交付

- 领域档案
- 决策事件
- 不可改快照
- 当前选择
- 关键假设
- 回填计划
- 模式和状态画像

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 写入 `.fde/state/decisions`
- 后续结果追加，不覆盖原判断

## 停止条件

- 决策人不是用户时标明权限
- 证据不足时可记录暂定选择但不能写成确定结论
- 不可逆高风险决定先提示专业核验

## 接续

- 商业判断用 fde-diagnose
- 回看旧决定用 fde-report

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
