# 公众号排版

<!-- KB-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.kb/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 已确认 Markdown
- 排版主题选择
- 图片和链接
- 公众号发布限制
- references/style-themes.json
- scripts/render_wechat.py

## 必须保留的能力

- 把 Markdown 转成微信公众号可粘贴 HTML
- 提供 15 个自有排版主题
- 支持主题预览和正式生成
- 保留正文内容
- 检查图片、链接和移动端显示

## 执行

1. 先验证稿件状态和资源路径。
2. 从 15 个自有主题中选择，或先生成主题预览。
3. 使用 `scripts/render_wechat.py` 转换标题、段落、引用、列表、图片和链接。
4. 生成可粘贴 HTML，检查移动端宽度和复制兼容。
5. 列出未找到的图片、外链和转换差异。

## 交付

- HTML 文件
- 预览说明
- 资源缺失
- 正文差异清单

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 写入内容库的 `待发布`，不覆盖 Markdown 原稿

## 停止条件

- 稿件未确认时不进入待发布
- 不修改正文观点
- 外部样式和脚本不写入公众号 HTML

## 接续

- 内容没审核用 kb-review

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
