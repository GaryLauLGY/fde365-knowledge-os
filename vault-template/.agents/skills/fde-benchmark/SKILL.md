# 对标研究

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 自己的目标和约束
- 候选对象的公开材料
- 知识库中的产品、客户和内容数据

## 必须保留的能力

- 从候选中筛选对标
- 评估用户指定的对标
- 比较公开且可观察的业务条件
- 提取可复测动作而不复制人设
- 记录实验和结果

## 执行

1. 先写清要解决的问题和不能照搬的条件。
2. 选择 3—5 个可比对象，记录来源和观察时间。
3. 按对象、做法、证据、适用条件和风险拆解。
4. 只提取能做小实验的动作，安排验证周期。

## 交付

- 候选筛选
- 可学动作
- 不适用部分
- 证据链接或文件
- 本周实验

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 研究记录写入方法库
- 实验结果写入 `发布数据/分析`，并关联对应已发布内容

## 停止条件

- 没有公开证据时不评价结果
- 不得把粉丝数直接当商业效果
- 不复制个人经历和虚构人设

## 接续

- 实验形成内容时用 fde-write
- 商业方向不清用 fde-diagnose

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
