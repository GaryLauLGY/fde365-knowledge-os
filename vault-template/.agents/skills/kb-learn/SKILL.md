# 学习循环

<!-- KB-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.kb/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 要解决的工作问题
- 现有方法库
- 上次练习和反馈
- 可投入时间

## 必须保留的能力

- 把一个课题拆成连续学习内容
- 根据上一篇反馈调整深度、角度和节奏
- 每轮提供说明、示例和练习
- 保留学习进度并生成下一篇

## 执行

1. 把课题拆成连续文章，但一次只生成下一篇。
2. 读取上一篇反馈，判断需要加深、换角度、放慢或增加练习。
3. 本篇提供说明、示例、练习和反馈问题。
4. 保存学习进度，根据实际反馈决定下一篇，不预先写完整课程。

## 交付

- 本轮目标
- 必要知识
- 练习
- 完成标准
- 反馈问题

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 学习记录写入方法库或 `.kb/state/learning`

## 停止条件

- 没有实际任务时不堆课程
- 反馈未返回时不假装掌握
- 需要最新知识时先核验来源

## 接续

- 形成方法时用 kb-library 收录
- 形成内容时用 kb-write

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
