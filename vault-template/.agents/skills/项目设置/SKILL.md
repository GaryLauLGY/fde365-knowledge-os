# 项目设置

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 项目根目录
- 现有 AGENTS.md、CLAUDE.md 和 skills
- 当前 FDE 工作台
- 真源位置

## 必须保留的能力

- 审计 Agent 规则文件和技能目录
- 确定规则真源和技能真源
- 统一名称和入口
- 仅处理当前 Vault 内的 FDE 规则与技能
- 先预览再迁移

## 执行

1. 盘点现有规则、技能和重复副本。
2. 选择一个规则真源和一个技能真源。
3. 生成当前 Vault 内的规则与技能目录整理方案，不创建跨客户端连接。
4. 先预览新增、修改和冲突，确认后执行。

## 交付

- 当前结构
- 真源选择
- 目标结构
- 变更预览
- 验证结果

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 只在当前项目内写入口文件
- 不写入全局客户端配置、全局技能目录或 Shell 环境变量

## 停止条件

- 不删除原有配置
- 规则冲突时不自动合并
- 不得把客户知识库连接到其他项目

## 接续

- 完成后用 知识体检

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
