# 资产整理方法

## 输入

- 六类资产目录
- 文件名、标题、来源和修改时间
- 现有 Wikilink、反向链接和“关联资产”章节
- 用户现有命名规则
- `scripts/inventory_assets.py`
- references/unit-schema.md、topic-map-schema.md、assembly-schema.md

## 步骤

1. 运行只读清单，确认内容规模、边界、重复和无来源文件。
2. 按 unit-schema 把长文拆成观点、问题、案例、方法和方案单元，每个单元保留来源。
3. 按 topic-map-schema 连接相关单元，记录支持、冲突、例子和版本关系。
4. “整理关联”任务先列出两端完整路径、关系类型和依据；需要批准时等待确认。
5. 确认后在两端笔记的 `## 关联资产` 中分别写入指向对方的完整路径 Wikilink，并重新读取验证。
6. 按 assembly-schema 从单元装配选题稿，不复制旧文章。
7. 生成迁移和写入预览，用户确认后分批执行并记录日志。

Canvas 只在用户明确要求时生成，不能替代两端 Markdown 双链。

## 交付

- 资产清单
- 内容单元
- 主题地图
- 跨库双链预览与写入记录
- 选题装配稿
- 迁移预览
- 执行日志

## 停止

- 不能确认真源时不合并
- 没有来源时不伪造
- 关系依据不足时不写双链
- 批量移动和覆盖必须确认
