# 材料入库

<!-- KB-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.kb/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 收件箱中的原始文件
- 六类资产库现有条目
- 重复记录和命名规则

## 必须保留的能力

- 通读整份材料后再拆分
- 提取认知、方法、故事数据、情绪原话、选题和待办
- 生成结构化处理稿
- 确认后分流入库并保留原文件

## 执行

1. 登记原文件路径、时间、类型和处理批次。
2. 通读全文，分开提取原话、事实、判断、方法、故事、选题和待办。
3. 与现有资产比对，标出新增、补充、冲突和重复。
4. 先生成分流预览，确认后写入并把处理记录放入已处理目录。

## 交付

- 原文摘要
- 分流清单
- 冲突和重复
- 写入文件
- 未处理内容

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 原文件保持不变
- 处理稿写入 inbox.processed
- 确认后的资产写入对应库并附来源

## 停止条件

- 文件读不全时停止
- 分类不确定时留在待确认区
- 不得用摘要替换原始文件

## 接续

- 需要选题时用 kb-topics
- 需要查资料时用 kb-library

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
