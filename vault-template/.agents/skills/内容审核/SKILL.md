# 内容审核

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 待审核稿
- 对应选题
- 个人说明书
- 产品和客户事实
- 来源材料
- 平台要求

## 必须保留的能力

- 默认只诊断不改稿
- 支持公众号、小红书、口播和短文案
- 先检查事实和定位，再检查内容质量
- 给出具体位置和修改顺序
- 用户确认后另存改稿

## 执行

1. 先核对事实、数字、引用和来源。
2. 再检查读者问题、主线、证据、行动和平台适配。
3. 把问题按必须改、建议改和保留原样分类。
4. 只给最小修改方案；用户要求改稿后才生成新版本。

## 交付

- 发布判断
- 必须改的问题和位置
- 证据缺口
- 保留项
- 修改顺序

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 诊断记录写入 `待审核` 对应文件
- 改稿另存版本
- 通过后才移入 `待发布`

## 停止条件

- 来源冲突时阻止发布
- 平台规则不确定时标记待核验
- 不为了顺滑重写本人原话

## 接续

- 开头问题用 设计开头
- 段落问题用 检查段落
- AI 痕迹用 检查表达

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
