# 保存进度

<!-- KB-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.kb/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 当前对话中的任务
- 本轮读取和写入的文件
- 用户已经确认的结论

## 必须保留的能力

- 保存目标、来源、结论、未知项和下一步
- 写入当前知识库而非用户主目录
- 生成状态 ID 和恢复提示

## 执行

1. 提取当前目标和范围。
2. 列出已完成动作及文件路径。
3. 分开保存已确认、推断、未知和被否定方向。
4. 生成短 ID 和下一次恢复入口。

## 交付

- 状态 ID
- 完成项
- 来源
- 未知项
- 下一步
- 恢复提示

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 写入 `.kb/state/sessions`，不写用户主目录

## 停止条件

- 没有明确任务时不创建空状态
- 敏感信息按用户要求删减
- 不保存未获授权的外部内容

## 接续

- 恢复时用 kb-resume
- 多次状态汇总用 kb-report

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
