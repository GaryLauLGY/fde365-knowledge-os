# 选题清单

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 客户高频问题
- 产品异议
- 案例中的变化
- 个人观点
- 已发布内容和发布数据分析

## 必须保留的能力

- 从六类资产和真实用户声音找题
- 检查是否是真需求
- 检查是否适合当前个人定位和产品
- 检查角度是否与常见写法重复
- 把选中题写入内容库

## 执行

1. 先确认平台和本次内容目标。
2. 从不同资产库各找证据，不从热词凭空造题。
3. 把候选题写成对象、矛盾、证据和预期动作。
4. 去除与已发布内容重复的题，按证据强度和业务关系排序。

## 交付

- 5—10 个候选题
- 每题来源
- 目标读者
- 核心矛盾
- 建议平台
- 不选原因

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 用户选中的题写入内容库的 `选题`
- 记录来源和创建日期

## 停止条件

- 没有真实来源时不伪装成知识库选题
- 平台未定时只给方向，不写成稿

## 接续

- 选题确认后用 fde-write
- 方向存疑时用 fde-diagnose

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
