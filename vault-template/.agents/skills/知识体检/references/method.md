# 知识库体检方法

## 输入

- `.fde/config.yaml`
- 六类资产路径
- 收件箱和内容阶段
- `.fde` 运行目录
- AGENTS.md、CLAUDE.md 和已安装 中文技能清单

## 步骤

1. 验证配置字段、路径边界和目录可读性。
2. 统计六类资产的文件数、来源覆盖和最近更新。
3. 对照 AGENTS.md、CLAUDE.md、技能目录和实际项目状态，找路径、版本、数字和状态冲突。
4. 检查待处理材料、重复入库、内容阶段冲突和运行文件越界。
5. 把问题分为阻塞、要处理和提醒，只给出有证据的问题。

## 交付

- 能否使用
- 问题路径和证据
- 影响
- 建议动作
- 等待确认的修正

## 停止

- 配置不存在时停止并询问根目录
- 业务事实冲突时不自动选边
- 不把空库当成损坏
