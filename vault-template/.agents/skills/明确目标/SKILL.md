# 明确目标

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 用户原话
- 当前业务阶段
- 已有资源
- 不能接受的结果

## 必须保留的能力

- 保留用户原目标
- 找出无法检查的词
- 改写为对象、结果、边界、证据和时间
- 给出验收方式和第一步

## 执行

1. 保留原句，标出无法检查的词。
2. 追问想让谁发生什么变化，以及用什么证据确认。
3. 写出范围、截止点、资源和不做事项。
4. 生成最小目标版本和验收方式。

## 交付

- 原目标
- 可检查目标
- 验收证据
- 边界
- 第一步

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 用户确认后写入项目状态或决策记录

## 停止条件

- 用户不接受量化时用可观察事实替代
- 不替用户决定价值取舍
- 目标与事实冲突时标出

## 接续

- 执行受阻用 推进一步
- 需要拆问题用 整理问题

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
