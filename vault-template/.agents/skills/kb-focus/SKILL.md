# 优先事项

<!-- KB-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.kb/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 当前目标
- 任务列表
- 依赖关系
- 时间与资源
- 最近结果

## 必须保留的能力

- 识别贪快和绕开摩擦的做法
- 区分能积累资产的慢动作与低效忙碌
- 说明摩擦会留下什么可复用资产
- 安排一个长期主动作和停止清单

## 执行

1. 删除与当前目标无关的任务。
2. 标出会阻塞其他任务的前置项。
3. 比较每项的结果信号、成本和可逆性。
4. 只保留一个主动作、一个维护动作和一个观察项。

## 交付

- 当前约束
- 主动作
- 维护动作
- 暂停清单
- 复查条件

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 确认后写入 `.kb/state` 的当前计划

## 停止条件

- 目标不清时不排序
- 紧急合规或安全问题优先处理
- 不把所有任务都标成重点

## 接续

- 目标不清用 kb-goal
- 动作推不动用 kb-action

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
