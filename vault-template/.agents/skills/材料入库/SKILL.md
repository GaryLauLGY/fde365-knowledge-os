# 材料入库

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。
5. 录音、聊天、会议、图片和文档只是“材料形式”，不得当作第 7 个资产库。

## 读取

- 收件箱中的原始文件
- 六类资产库现有条目
- 重复记录和命名规则

## 必须保留的能力

- 通读整份材料后再拆分
- 提取认知、方法、故事数据、情绪原话、选题和待办
- 生成结构化处理稿
- 确认后分流入库并保留原文件
- 分开标记材料形式与六类资产归属
- 允许一个证据单元建议多个资产去向
- 录音转写中的人名、数字和时间戳不确定时必须标记

## 执行

1. 登记原文件路径、时间、材料形式和处理批次。
2. 录音材料保留原音频并读取转写；人名、数字、日期和时间戳听不清时标为待确认。
3. 通读全文，拆成可追溯的证据单元，分开提取原话、事实、判断、方法、故事、选题和待办。
4. 对每个证据单元独立判断“个人说明书、产品库、客户需求库、素材案例库、方法论库、内容生产”中的一个或多个去向。
5. 与现有资产比对，标出新增、补充、冲突和重复。
6. 先在当前 Agent 对话中生成分流预览；不得把预览另存为 `inbox.pending` 中的新材料。确认后再写入正式资产，插件会在原始材料记录上自动标记处理状态。

## 交付

- 原文摘要
- 分流清单：来源片段/时间戳、材料形式、资产去向（可多选）、新增/补充/冲突/重复、置信度/未知项
- 冲突和重复
- 写入文件
- 未处理内容

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 原文件保持不变
- 分流预览只进入当前 Agent 对话与 `7-系统/AI协作` 运行记录，不在原始材料列表新增文件
- 原始材料记录保持原路径，处理完成后只更新 `status` 和 `processed_at`
- 确认后的资产写入对应库并附来源

## 停止条件

- 文件读不全时停止
- 分类不确定时留在待确认区
- 没有强证据时不得为了“必须分类”而猜一个资产库
- 不得用摘要替换原始文件

## 接续

- 需要选题时用 生成选题
- 需要查资料时用 查询知识

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
