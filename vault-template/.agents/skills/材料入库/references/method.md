# 材料入库方法

## 输入

- 收件箱中的原始文件
- 六类资产库现有条目
- 重复记录和命名规则

## 步骤

1. 登记原文件路径、时间、材料形式和处理批次。录音、聊天、会议、图片和文档是形式，不是六类资产的业务归属。
2. 录音保留原音频并读取转写；对听不清的人名、数字、日期和时间戳显式标记不确定。
3. 通读全文，拆成可追溯证据单元，分开提取原话、事实、判断、方法、故事、选题和待办。
4. 每个证据单元可建议一个或多个六类资产去向；没有强证据时留在待确认。
5. 与现有资产比对，标出新增、补充、冲突和重复。
6. 先在当前 Agent 对话中生成分流预览，不在待处理目录创建新的预览材料；确认后写入正式资产，原始材料记录原地自动标记为已处理。

## 交付

- 原文摘要
- 分流清单（来源片段/时间戳、材料形式、资产去向、处理动作、置信度/未知项）
- 冲突和重复
- 写入文件
- 未处理内容

## 停止

- 文件读不全时停止
- 分类不确定时留在待确认区
- 不得用摘要替换原始文件
