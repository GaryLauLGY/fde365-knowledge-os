# 内容标题

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 正文或提纲
- 目标读者
- 平台
- 可用数字和结果
- 禁用表达
- references/title-patterns.json

## 必须保留的能力

- 从 75 个自有标题结构中筛选
- 根据平台、读者和正文选择
- 输出候选和 Top 3
- 说明结构选择原因
- 检查标题承诺能被正文支持

## 执行

1. 先用一句话概括正文真实交付。
2. 提取对象、问题、变化和限制。
3. 从 75 个自有结构中按平台和材料筛选，再生成 8—12 个标题。
4. 检查每个标题是否能由正文支持，筛出 3 个并说明使用的结构。

## 交付

- 候选标题
- Top 3
- 各自侧重点
- 风险词
- 正文支持位置

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 选定标题写回草稿头部，保留旧标题记录

## 停止条件

- 正文没有明确交付时先不做标题
- 不得添加正文没有的数字或结果
- 平台规则不确定时标记核验

## 接续

- 标题确定后用 fde-review

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
