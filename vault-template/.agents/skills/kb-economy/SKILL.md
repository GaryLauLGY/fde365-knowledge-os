# 交易与激励

<!-- KB-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.kb/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 交易双方
- 价格和成本
- 可替代方案
- 规则和信息
- 实际行为

## 必须保留的能力

- 用分散知识视角检查信息问题
- 用行动与选择视角检查成本和机会
- 用经营者视角综合价格和激励
- 形成三席对话而不冒充真人
- 落到可观察的市场信号

## 执行

1. 建立三席：分散知识席、行动选择席、经营者席，不冒充历史人物。
2. 分散知识席检查信息在哪些人手里、价格传递了什么。
3. 行动选择席检查谁在选择、付出什么和放弃什么。
4. 经营者席检查价格变化会改变谁的激励、风险和替代方案。
5. 三席互相质疑后，列出可以观察的市场信号和理论无法直接判断的部分。

## 交付

- 参与方
- 交换内容
- 激励变化
- 信息缺口
- 可观察信号
- 限制

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 确认后的分析可写入方法库

## 停止条件

- 不把理论当成事实证据
- 不预测具体市场价格
- 金融投资问题要求专业核验

## 接续

- 落到具体生意用 kb-diagnose
- 概念不清用 kb-define

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
