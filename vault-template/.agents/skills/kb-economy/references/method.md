# 交易与激励方法

## 输入

- 交易双方
- 价格和成本
- 可替代方案
- 规则和信息
- 实际行为

## 步骤

1. 建立三席：分散知识席、行动选择席、经营者席，不冒充历史人物。
2. 分散知识席检查信息在哪些人手里、价格传递了什么。
3. 行动选择席检查谁在选择、付出什么和放弃什么。
4. 经营者席检查价格变化会改变谁的激励、风险和替代方案。
5. 三席互相质疑后，列出可以观察的市场信号和理论无法直接判断的部分。

## 交付

- 参与方
- 交换内容
- 激励变化
- 信息缺口
- 可观察信号
- 限制

## 停止

- 不把理论当成事实证据
- 不预测具体市场价格
- 金融投资问题要求专业核验
