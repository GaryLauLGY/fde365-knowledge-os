# 导出聊天方法

## 输入

- 用户指定的 Agent 和项目
- 本地会话索引
- 用户选择的会话范围
- `scripts/export_chat.py`

## 步骤

1. 先识别宿主和本地会话位置，不扫描无关目录。
2. 使用 `scripts/export_chat.py list` 列出日期、项目和首条消息，让用户选择。
3. 支持单选、多选、最近记录和全部；导出前显示会话数、目标目录和隐私范围。
4. 使用脚本只提取用户与助手可读文本，生成 Markdown 和来源清单。

## 交付

- 导出文件列表
- 会话时间范围
- 消息数量
- 未能解析的记录

## 停止

- 宿主格式未知时不猜解析规则
- 未获确认时不批量导出
- 含敏感信息时先提醒用户选择范围
