# 内容标题方法

## 输入

- 正文或提纲
- 目标读者
- 平台
- 可用数字和结果
- 禁用表达
- references/title-patterns.json

## 步骤

1. 先用一句话概括正文真实交付。
2. 提取对象、问题、变化和限制。
3. 从 75 个自有结构中按平台和材料筛选，再生成 8—12 个标题。
4. 检查每个标题是否能由正文支持，筛出 3 个并说明使用的结构。

## 交付

- 候选标题
- Top 3
- 各自侧重点
- 风险词
- 正文支持位置

## 停止

- 正文没有明确交付时先不做标题
- 不得添加正文没有的数字或结果
- 平台规则不确定时标记核验
