# 传播复盘

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 原内容
- 平台数据
- 评论和转发语
- 发布时间和分发方式
- 同账号基线

## 必须保留的能力

- 没有发布数据时只列出所需指标，不下传播效果结论
- 有数据时用评论和指标验证
- 分析受众情绪、有效立场和传播动作
- 给出可继续讨论的方向
- 区分相关性和因果

## 执行

1. 先确认用户是否上传或回填了真实发布数据，以及数据对应哪一篇已发布内容。
2. 没有数据时只列出需要用户补充的指标和导出文件，不生成数据结论。
3. 有数据时确认口径和基线，拆分曝光、停留、互动、转发和转化信号。
4. 用评论原话验证受众情绪和有效立场，不替读者发明动机。
5. 输出可继续讨论的方向、反证和下一次实验。

## 交付

- 数据摘要
- 有效信号
- 可能机制
- 反证
- 下一次实验

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 分析记录写入内容库的 `发布数据/分析`，关联原发布稿
- 不移动原发布稿，不改变其 `已发布` 阶段

## 停止条件

- 没有用户上传或回填的真实数据时不生成数据结论
- 平台口径不同不直接横比
- 相关性不写成因果

## 接续

- 下一题用 生成选题
- 下一稿用 内容写作

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
