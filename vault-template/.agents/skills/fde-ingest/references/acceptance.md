# 验收

- [ ] fde-ingest 使用当前知识库配置。
- [ ] 读取范围与任务有关。
- [ ] 事实、推断和未知分开。
- [ ] 关键判断有来源。
- [ ] 破坏性动作先确认。
- [ ] 输出包含：原文摘要、分流清单、冲突和重复、写入文件、未处理内容。
- [ ] 能力：通读整份材料后再拆分。
- [ ] 能力：提取认知、方法、故事数据、情绪原话、选题和待办。
- [ ] 能力：生成结构化处理稿。
- [ ] 能力：确认后分流入库并保留原文件。
- [ ] 材料形式与六类资产归属分开，录音不被当作独立资产库。
- [ ] 同一证据单元可预览多个资产去向，归属不明时留在待确认。
- [ ] 录音转写中不确定的人名、数字、日期和时间戳已标记。
- [ ] 分流预览只出现在当前对话和 AI 运行记录，没有在待处理目录新增材料。
- [ ] 处理完成只更新原始材料记录状态，没有自动移动或删除原始材料；删除仅来自用户在材料列表中的独立确认操作。
