# 建库采访

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 现有六类资产
- 已完成的采访状态
- 用户明确不回答的范围

## 必须保留的能力

- 同时覆盖业务资料和个人资料
- 一次只问一个问题并根据回答追问
- 把确认结果分流到六类资产库
- 支持暂停、跳过、重做和恢复

## 执行

1. 先盘点哪些库为空，确定本轮只补一个主题。
2. 围绕具体事件提问，先问事实，再问判断和结果。
3. 每 5 个问题汇总一次：原话、事实、推断、待确认。
4. 用户确认汇总后再拆分到对应资产库。

## 交付

- 采访原话记录
- 可确认事实
- 用户自己的判断
- 仍需补问的事项
- 建议写入位置

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 原始问答写入收件箱或采访记录
- 确认后的条目分别写入六类资产库
- 采访进度写入 `.fde/state`

## 停止条件

- 用户要求暂停时保存进度
- 用户不确认汇总时不写入正式资产
- 不得替用户补经历、客户原话或数字

## 接续

- 有录音转写时转 fde-ingest
- 底稿完成后回 fde-start

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
