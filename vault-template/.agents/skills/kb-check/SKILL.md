# 文字痕迹检查

<!-- KB-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.kb/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 待检查文本
- 老板说明书中的原话和禁区
- 内容来源
- 用户要求保留的表达

## 必须保留的能力

- 扫描空泛结构和常见 AI 写作特征
- 标出具体句子和问题类型
- 对照老板表达检查偏差
- 默认只诊断不改写
- 不声称能证明真实作者

## 执行

1. 先找没有来源的事实和过度确定的判断。
2. 再找重复句式、均匀段落、概念堆叠和替读者总结。
3. 对照老板原话标出语气和用词偏差。
4. 按删、补证据、还原原话和保留分组。

## 交付

- 问题位置
- 问题类型
- 为什么有问题
- 最小修改动作
- 应保留内容

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 默认不改原文；确认后另存版本

## 停止条件

- 不能根据文本判断是否由 AI 实际生成
- 不删除行业必要术语
- 不为了口语化添加虚构场景

## 接续

- 整体审核用 kb-review
- 需要写稿用 kb-write

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
