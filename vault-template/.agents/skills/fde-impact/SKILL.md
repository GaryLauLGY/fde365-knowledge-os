# 受众反应

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 内容稿
- 目标客户资产
- 客户原话
- 发布数据或反馈
- 预期行动

## 必须保留的能力

- 判断目标读者是否明确
- 检查问题和情绪是否来自真实材料
- 定位不共鸣的段落
- 给出具体修正动作
- 没有发布数据时不预测实际流量

## 执行

1. 标出文章声称在对谁说。
2. 对照客户原话检查问题是否真实存在。
3. 检查内容是否给出新的判断、证据和下一步。
4. 区分定位偏差、材料不足、表达模糊和行动门槛。

## 交付

- 目标读者匹配
- 有效段落
- 失焦位置
- 缺少的证据
- 优先修改项

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 诊断写入内容审核记录
- 不自动改正文

## 停止条件

- 没有目标读者时不判断共鸣
- 没有发布数据时不声称传播效果
- 不编造受众心理

## 接续

- 传播原因用 fde-spread
- 需要改稿用 fde-review

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
