# 查库与维护

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 用户问题中的对象、时间和用途
- 相关资产库
- 索引和最近版本

## 必须保留的能力

- 空目录时建立最小知识库
- 已有资料时生成导航和真源说明
- 查询时返回答案、来源和版本
- 支持收录、纠错、最新版判断和导航更新

## 执行

1. 空目录时建立六类最小目录、配置和导航；已有资料时先生成导航，不搬文件。
2. 把问题拆成检索词、资产类型和时间范围。
3. 先查导航与索引，再打开少量候选文件核对原文。
4. 按已确认事实、冲突、推断和缺口返回，并指出当前版本和真源。
5. 新增、纠错或设为最新版时先展示目标文件、旧版本和来源，再更新导航。

## 交付

- 直接回答
- 来源路径
- 冲突或版本差异
- 未找到的内容
- 建议维护动作

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 新增条目写入对应资产库
- 索引变更写入 `.fde/indexes`
- 不覆盖旧版本

## 停止条件

- 来源不足时明确说未找到
- 跨项目读取必须得到用户明确授权
- 删除和合并先确认

## 接续

- 结构混乱用 fde-organize
- 整体检查用 fde-health

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
