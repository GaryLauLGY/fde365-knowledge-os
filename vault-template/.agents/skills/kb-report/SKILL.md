# 状态报告

<!-- KB-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.kb/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 选定任务的状态文件
- 决策记录
- 关联资产和结果
- 报告读者

## 必须保留的能力

- 合并同一任务的多次状态
- 保留判断变化和时间线
- 输出可交付 Markdown
- 附来源、风险和未完成项

## 执行

1. 按时间排序状态，不先写结论。
2. 合并重复事实，保留判断变化和原因。
3. 区分已完成、进行中、阻塞和未知。
4. 为每个关键结论附来源路径。

## 交付

- 摘要
- 时间线
- 关键决定
- 结果
- 风险和未知
- 下一步
- 来源附录

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 写入 `.kb/reports` 或用户指定目录
- 不修改源状态

## 停止条件

- 状态属于不同任务时不强行合并
- 缺少来源的结论标明
- 对外报告先检查敏感信息

## 接续

- 继续执行回 kb-start
- 复盘决定用 kb-decide

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
