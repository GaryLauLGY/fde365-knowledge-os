# 多角度讨论

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 讨论问题
- 参与角色或职责
- 六类资产中的相关事实
- 需要做出的决定

## 必须保留的能力

- 根据问题推荐职责或接受用户指定角色
- 角色依据可验证理论和知识库事实发言
- 支持连续多轮使用同一组角色
- 输出共识、分歧和缺失证据
- 支持明确结束讨论

## 执行

1. 把问题和决策标准写清楚。
2. 用户未指定角色时，按问题推荐 3—5 个职责；用户指定时沿用。
3. 为每个角色限定证据和关注点，逐轮提出观点、质疑和回应。
4. 把角色组和未解决问题写入当前会话状态，后续输入继续同一组。
5. 用户说结束时退出，并列共识、分歧、缺证据和负责动作。

## 交付

- 角色观点
- 证据
- 分歧
- 共识
- 待验证项
- 行动归属

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 用户需要时把结论写入决策记录

## 停止条件

- 不得声称是真人意见
- 角色没有证据时必须承认
- 没有决策问题时不无限发散

## 接续

- 需要正式决策用 记录决定
- 商业问题用 商业诊断

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
