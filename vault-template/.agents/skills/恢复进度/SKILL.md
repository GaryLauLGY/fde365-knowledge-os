# 恢复进度

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- `.fde/state/sessions`
- 用户指定的状态 ID
- 状态中引用的文件

## 必须保留的能力

- 列出可恢复状态
- 恢复最近或指定状态
- 核对引用文件是否变化
- 继续时创建新版本

## 执行

1. 列出可恢复状态的时间、任务和完成度。
2. 读取选中状态，核对引用文件是否存在或更新。
3. 说明上次结论、变化和仍未知事项。
4. 让用户确认继续点后再执行。

## 交付

- 恢复的状态
- 文件变化
- 已完成项
- 待办
- 建议继续点

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 继续工作后创建新状态版本，不覆盖旧状态

## 停止条件

- 找不到状态时停止并列出可用项
- 关键来源已变更时不沿用旧结论
- 不恢复其他知识库的状态

## 接续

- 需要汇总用 整理报告
- 继续任务回对应技能

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
