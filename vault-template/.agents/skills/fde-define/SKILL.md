# 词义校准

<!-- FDE-OWNED-WORKFLOW: v1 -->

## 开始前

1. 从当前目录向上找到 `.fde/config.yaml`，按配置解析六类资产库。
2. 只读取本任务需要的文件，不跨知识库搜索。
3. 把库内事实、用户本轮信息、当前推断和未知项分开。
4. 原始材料不覆盖；删除、移动和批量写入先确认。

## 读取

- 词出现的原句
- 说话人和场景
- 该词影响的决定
- 知识库中已有用法

## 必须保留的能力

- 收集一个词在不同场景的用法
- 换成可观察的人、动作和结果
- 建立当前任务的暂定定义
- 提供包含项、排除项和反例

## 执行

1. 收集同一个词在当前材料中的不同用法。
2. 把每种用法换成可观察的人、动作和结果。
3. 指出哪些用法能合并，哪些必须分开。
4. 为当前任务选择一个暂定定义和反例。

## 交付

- 用法列表
- 操作性定义
- 包含项
- 不包含项
- 反例
- 对当前决定的影响

每个关键判断附来源路径；没有来源的内容标为推断或待确认。

## 写回

- 用户确认后写入方法库的词汇表

## 停止条件

- 没有上下文时不提供唯一真定义
- 行业术语可能变化时标记待核验
- 不把定义争论代替实际决定

## 接续

- 目标句仍模糊用 fde-goal
- 问题边界不清用 fde-question

来源沿革只用于追溯，不作为运行指令。需要追溯时读取 `references/source-map.md`。
