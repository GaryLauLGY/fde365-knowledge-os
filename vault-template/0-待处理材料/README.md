# 待处理材料

这里是通用收件箱，保存尚未整理和已经整理的原始材料。录音、聊天导出、会议纪要、文档、图片和其他文件都可以放在这里。它不是第 7 个资产库。

录音不再使用独立的顶层目录：原音频、转写稿和处理记录都归在这个大类下。“录音”只描述材料形式，其中的证据仍按个人、产品、客户、案例、方法和内容六类资产判断去向。

## 目录

- `待处理`：永久保留各类原始材料；同一条记录用状态区分待处理和已处理。
- `已处理记录`：兼容旧版本的处理记录，新的原始材料不会因为完成处理而移动到这里。

## 流程

1. 把原始文件放进待处理目录。
2. 调用 `/fde-ingest`。
3. 在右侧 Agent 对话查看分流预览；预览不会作为新材料出现在列表中。
4. 确认后写入六类资产库。
5. 处理成功后原材料记录自动标记为已处理并排在列表底部；处理本身不会移动或删除原文件。
6. 如不再需要材料，可在原始材料列表单项删除，或勾选多项后批量删除；确认后选中收件记录和对应原始文件会一并移入回收站，正式资产和处理记录保留。
