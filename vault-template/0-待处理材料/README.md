# 待处理材料

这里是通用收件箱，保存尚未整理和已经整理的原始材料。录音、聊天导出、会议纪要、文档、图片和其他文件都可以放在这里。它不是第 7 个资产库。

录音不再使用独立的顶层目录：原音频、转写稿和处理记录都归在这个大类下。“录音”只描述材料形式，其中的证据仍按个人、产品、客户、案例、方法和内容六类资产判断去向。

## 目录

- `待处理`：保留待判断、待分流的各类原始材料。
- `已处理记录`：处理结果、批次记录和结构化笔记。

## 流程

1. 把原始文件放进待处理目录。
2. 调用 `/fde-ingest`。
3. 先查看分流预览。
4. 确认后写入六类资产库。
5. 原文件不删除；处理记录写明原始路径。
