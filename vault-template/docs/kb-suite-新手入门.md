# kb-suite 新手入门

## 第一次使用

先确认当前目录包含 `.kb/config.yaml`。然后输入：

```text
/kb-start
```

`kb-start` 会先判断知识库是否为空，再把任务交给一个具体 Skill。

- 知识库为空：使用 `/kb-interview`。
- 有录音、聊天记录或旧文档：使用 `/kb-ingest`。
- 已经有六类资产：根据任务进入诊断、选题、写作或审核。

## 35 个 Skill

### 建库和维护

- `/kb-start`：主入口和任务路由。
- `/kb-interview`：采访用户，建立六类资产。
- `/kb-ingest`：处理录音、聊天记录和旧文档。
- `/kb-export`：导出聊天记录，交给导入流程。
- `/kb-library`：搜索、录入和维护知识库。
- `/kb-health`：检查目录、来源、索引和运行状态。
- `/kb-organize`：整理已有内容资产。
- `/kb-setup`：建立 Agent 工作目录。
- `/kb-connect`：把 Skill 真源连接到指定 Agent 技能目录。
- `/kb-update`：检查或更新这一套 `kb-*`。
- `/kb-safety`：检查 Skill 中的可疑行为。

### 生意和行动

- `/kb-diagnose`：诊断生意、产品、定价和客户问题。
- `/kb-benchmark`：研究对标对象。
- `/kb-define`：拆解模糊概念。
- `/kb-goal`：把愿望改成可检查的目标。
- `/kb-question`：把困惑整理成可处理的问题。
- `/kb-decide`：记录和复盘决策。
- `/kb-action`：处理知道要做但没有行动的问题。
- `/kb-focus`：找到当前约束，确定主动作和暂停清单。
- `/kb-learn`：根据反馈继续学习。

### 内容生产

- `/kb-topics`：从六类资产中找选题。
- `/kb-write`：按平台和任务写内容。
- `/kb-review`：内容审核总入口。
- `/kb-hook`：检查短视频开头。
- `/kb-title`：生成小红书标题。
- `/kb-flow`：检查逐字稿衔接。
- `/kb-impact`：检查文稿是否击中受众。
- `/kb-spread`：分析内容的传播原因。
- `/kb-check`：检查空泛表达、无来源事实和表达偏差。
- `/kb-format`：生成微信公众号 HTML。

### 讨论和状态

- `/kb-discuss`：按不同职责讨论一个具体决定。
- `/kb-economy`：从价格、成本、选择、激励和信息检查判断。
- `/kb-save`：保存当前任务状态。
- `/kb-resume`：恢复上次状态。
- `/kb-report`：把多次记录整理成报告。

## 写入规则

- 原始材料保留在 `0-录音处理/待处理录音` 或用户指定的收件位置。
- 新增资产要记录来源。
- 不能确定分类时，先放待处理区，不要猜。
- 删除和覆盖前要让用户确认。
- 内容草稿、审核稿和发布稿分开保存。

## 常用流程

```text
采访或导入
→ 六类资产库
→ 选题
→ 写作
→ 审核
→ 发布和复盘
```

遇到不确定的任务，回到 `/kb-start`。
