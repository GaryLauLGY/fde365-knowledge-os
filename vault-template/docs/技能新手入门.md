# 技能新手入门

## 第一次使用

先确认当前目录包含 `.fde/config.yaml`。然后输入：

```text
/开始使用
```

`开始使用` 会先判断知识库是否为空，再把任务交给一个具体技能。

- 知识库为空：使用 `/建库采访`。
- 有录音、聊天记录或旧文档：使用 `/材料入库`。
- 已经有六类资产：根据任务进入诊断、选题、写作或审核。

## 34 个技能

### 建库和维护

- `/开始使用`：主入口和任务路由。
- `/建库采访`：采访用户，建立六类资产。
- `/材料入库`：处理录音、聊天记录和旧文档。
- `/导出会话`：导出聊天记录，交给导入流程。
- `/查询知识`：搜索、录入和维护知识库。
- `/知识体检`：检查目录、来源、索引和运行状态。
- `/整理资产`：整理已有资产；“整理关联”会在确认依据后，把跨库关系写入两端真实 Obsidian 双链。
- `/项目设置`：建立 Agent 工作目录。
- `/检查更新`：检查或更新这一套 中文技能。
- `/安全检查`：检查技能中的可疑行为。

### 生意和行动

- `/商业诊断`：诊断生意、产品、定价和客户问题。
- `/研究对标`：研究对标对象。
- `/定义概念`：拆解模糊概念。
- `/明确目标`：把愿望改成可检查的目标。
- `/整理问题`：把困惑整理成可处理的问题。
- `/记录决定`：记录和复盘决策。
- `/推进一步`：处理知道要做但没有行动的问题。
- `/确定焦点`：找到当前约束，确定主动作和暂停清单。
- `/边做边学`：根据反馈继续学习。

### 内容生产

- `/生成选题`：从六类资产中找选题。
- `/内容写作`：按平台和任务写内容。
- `/内容审核`：内容审核总入口。
- `/设计开头`：检查短视频开头。
- `/生成标题`：生成小红书标题。
- `/检查段落`：检查逐字稿衔接。
- `/读者匹配`：检查文稿是否击中受众。
- `/传播复盘`：分析内容的传播原因。
- `/检查表达`：检查空泛表达、无来源事实和表达偏差。
- `/公众号排版`：生成微信公众号 HTML。

### 讨论和状态

- `/多角度讨论`：按不同职责讨论一个具体决定。
- `/交易分析`：从价格、成本、选择、激励和信息检查判断。
- `/保存进度`：保存当前任务状态。
- `/恢复进度`：恢复上次状态。
- `/整理报告`：把多次记录整理成报告。

## 写入规则

- 原始材料保留在 `0-待处理材料/待处理` 或用户指定的收件位置。
- 新增资产要记录来源。
- 不能确定分类时，先放待处理区，不要猜。
- 删除和覆盖前要让用户确认。
- 内容草稿、审核稿和发布稿分开保存。

## 常用流程

```text
采访或导入
→ 六类资产库
→ 选题
→ 写作
→ 审核
→ 发布和复盘
```

遇到不确定的任务，回到 `/开始使用`。
