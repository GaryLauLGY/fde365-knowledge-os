FDE365 Knowledge OS

Windows 一键安装

不用安装 Obsidian，也不用配置 Base URL。准备好 Token，双击一次即可使用。

1购买 Token

前往 api.fde365.ai 购买或创建你的 Token。

2双击安装

双击 开始安装 FDE365.cmd，粘贴 Token 并选择模型。输入内容不会显示。

3开始工作

完成后打开桌面的“FDE365 工具”，可以进入知识库、Claude Code 或 Codex。

想从其他目录工作时，把文件夹拖到 Claude 或 Codex 图标上即可。

遇到问题

运行 检查安装.cmd。更新时运行 更新 FDE365.cmd；更新不会覆盖你的 Token 和笔记。
