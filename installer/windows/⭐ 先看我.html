FDE365 一键安装

只要双击“开始安装 FDE365.cmd”。

安装与登录

选择模型和新工作台。安装 Obsidian 与隔离的 Codex 引擎，不连接本机 Claude Code 或 Codex 配置。

在插件设置 → 账号与额度，用邮箱验证码登录，刷新余额、价格表或兑换 credits。固定服务：https://api.ipzsk.com/v1。

开始使用

桌面 FDE365 工具只保留知识库入口。34 个技能已放在当前知识库内。

遇到问题

运行“检查安装”。账号功能须后端接口已部署并可访问；当前接口仍待联调。更新会保留账号配置和知识材料，不自动删除旧版全局配置或快捷方式。
