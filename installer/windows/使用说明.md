# FDE365 Windows 一键安装

## 第一次使用

1. 打开 <https://api.fde365.ai/>，购买或创建 Token。
2. 双击“开始安装 FDE365.cmd”。
3. 粘贴 Token，选择模型，其余步骤由安装器自动完成。
4. 安装完成后，从桌面的“FDE365 工具”打开知识库、Claude Code 或 Codex。

AI 服务地址固定为 FDE365，安装时不会要求填写 Base URL。Token 只保存在当前 FDE365 工作台的 Obsidian 插件配置里。

安装器优先使用 Obsidian、Claude Code 和 Codex 的官方 Windows 下载入口。若 Claude 官方脚本不可达，会自动改用 npm 官方 Registry；若 Codex 官方脚本不可达，会下载并校验 OpenAI 官方 GitHub Release。全程不使用第三方镜像。

## 常用操作

- 双击“检查安装.cmd”：检查三个程序、知识库、插件和配置是否齐全，不会显示 Token。
- 双击“更新 FDE365.cmd”：更新插件和缺失的知识库模板文件，不覆盖笔记、Token 或其他用户数据。
- 可将任意文件夹拖到桌面的 Claude/Codex 启动图标上，从该文件夹开始工作。

## 遇到问题

先关闭 Obsidian，再运行“检查安装.cmd”。若仍有红色“缺失”提示，重新运行安装程序；已存在的工作台不会被覆盖。
