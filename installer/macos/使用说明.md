# FDE365 安装说明

解压后双击“开始安装 FDE365.command”，选择默认模型和新工作台目录。已有目标会改用新路径，保护原数据。
安装 Obsidian 与 Codex 运行引擎；不安装 Claude Code，不修改全局客户端、Shell 或系统环境变量。
打开插件设置 → 账号与额度，输入邮箱验证码登录。服务固定 https://api.ipzsk.com/v1，余额、价格与兑换全部由服务端提供。安装器不要求 Token。
桌面“FDE365 工具”只提供知识库入口。
已有安装使用“更新 FDE365.command”；程序会备份运行文件，保留 data.json 和用户材料。旧站 Token 不自动发送到新站，请重新登录。
“检查安装”只检查程序与文件完整性，不调用计费接口，不将尚未登录视为安装失败。

## 遇到问题

账号接口未部署或网络不通时，无法登录或兑换；不能用本地演示余额代替。新计费功能尚待后端联调。
旧版本留下的本机客户端配置、桌面启动器和 Vault 连接技能不会自动删除，以免破坏用户已有状态；新版本不再部署或调用它们。
