# FDE365 一键安装

第一次使用，只要双击 **开始安装 FDE365.command**，然后按照窗口里的中文提示操作。

安装器会自动完成三件事：

- 安装并打开 FDE365 知识库；
- 安装 Claude Code，并连接到 FDE365；
- 安装 Codex，并连接到 FDE365。

安装前，请先到 <https://api.fde365.ai/> 购买 Token。安装过程中把 Token 粘贴进去即可，输入时不会显示在屏幕上。

## 安装完成后怎么用

桌面会出现 **FDE365 工具** 文件夹：

- 双击 **打开 FDE365 知识库**：进入知识工作台；
- 双击 **打开 FDE365 Claude**：选择一个文件夹，让 Claude Code 帮你处理；
- 双击 **打开 FDE365 Codex**：选择一个文件夹，让 Codex 帮你处理。

## 更新和检查

- 收到新安装包后，双击 **更新 FDE365.command**；
- 遇到问题，双击 **检查安装.command**，把窗口结果截图发给服务人员。

更新不会删除你的笔记或 Token。首次安装会先备份原 Claude Code、Codex 和终端设置，然后将 Claude Code 与 Codex 改为只使用 FDE365 服务。
